# UI Keren Plugin Rules

Whenever the user asks—in **any language** (Indonesian, English, casual, or
formal)—to build, design, or redesign a website, landing page, web app UI, or
interactive frontend:

1. Activate and follow the `uikeren` skill (`SKILL.md` and its `references/`).
2. Always define a domain-tailored **Creative Direction Brief** before writing
   code (never copy reference site themes literally; adapt the craft to the
   user's topic).
3. Include **real, working JavaScript interactivity** from
   `skills/uikeren/references/js-recipes.md`—zero dead buttons, zero generic
   AI templates, zero AI slop.
